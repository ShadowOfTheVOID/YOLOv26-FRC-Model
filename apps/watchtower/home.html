Write key sends results to TBA

A write key is an Auth ID and an Auth Secret that TBA issues for one event. Get one: sign in at thebluealliance.com, then request write access for your event at thebluealliance.com/request/apiwrite (TBA approves it by hand, so ask a few days before). Once approved, the ID and secret are shown on your TBA account page. Keep the secret private: anyone with it can change your event's results on TBA. Test with one match before turning sending on for the day.

Read key optional, for importing teams

Only needed if Import from TBA finds no team list on the event page. Make one under Read API Keys on your TBA account page (thebluealliance.com/account). It cannot change anything on TBA.
